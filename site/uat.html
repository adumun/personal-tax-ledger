Requisitos y seguridad antes de instalar

Windows de escritorio x64

La UAT actual corresponde a la distribución Windows de escritorio. El paquete contiene PersonalTaxLedger-0.1.6-Setup.exe.

Advertencia de Windows

Esta UAT no es el paquete firmado/distribuido por Microsoft Store. Windows puede mostrar una advertencia SmartScreen o de reputación. Antes de continuar, verifica el nombre del archivo, el canal de descarga y el SHA-256 publicado en esta página.

Datos de prueba recomendados

No necesitas usar datos tributarios reales. Para esta validación externa recomendamos trabajar con datos ficticios o de prueba siempre que sea posible.

Datos locales

PTL funciona actualmente como aplicación local-first y no requiere una cuenta PTL en línea para sus capacidades locales. Revisa la política de privacidad antes de participar.

Antes de probar

Importante: PTL es un simulador de apoyo. No reemplaza al Servicio de Impuestos Internos (SII), no constituye una declaración oficial y no sustituye asesoría tributaria profesional. No utilices PTL como única fuente para tomar una decisión tributaria formal. Ante cualquier diferencia, prevalece la información oficial del SII.

Evita incluir información tributaria personal o sensible en reportes públicos. El feedback debería describir el problema sin exponer datos reales.
